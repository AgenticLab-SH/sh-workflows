# 비용 기록 (COST_LOG)

기능 1개 완료 또는 30~45분마다 한 줄씩 적는다. 실제로 본 값만 적고, 표시값이 없으면 `-`로 둔다. 턴 수는 대략이어도 된다.

| 시각 | 작업 단위 | 호출/턴 수(대략) | 읽은 주요 파일 | 큰 출력 여부 | 재시도 | 사용량 표시값(있으면) | 조치 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 10:40 | 예: 재고 집계 함수 | 6 | README, stock.py | 아니오 | 1 | - | 데이터는 프로파일 요약으로만 확인 |
|  |  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |  |

낭비 신호 확인: 같은 파일 재독 / 긴 출력 / 같은 실패 2회 이상 / 넓은 지시. 발견하면 조치 칸에 무엇을 바꿨는지 적는다.

## 설명용 3줄
