허용 상태: PASS / FAIL / NOT_RUN / BLOCKED / MANUAL_PASS / MANUAL_FAIL.
코드상 예상이나 도구의 '완료' 응답을 PASS로 바꾸지 않습니다.
현재 정책상 금지된 검사는 실행·위임하지 않고 NOT_RUN 사유만 적습니다.

근거 수준: 0 보고 / 1 저장 파일 / 2 해당 실행 / 3 기대 사례 일치 / 4 관련 회귀 관측.
