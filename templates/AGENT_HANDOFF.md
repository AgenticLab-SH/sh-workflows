# 에이전트·세션 인계

이 양식은 공개 예시다. 실제 기록은 허용된 `.cofa-workbench/docs/handoffs/<세션>.md`에 두며 공개 저장소로 올리지 않는다. 기존 정본이 있으면 그 경로를 연결한다.

- 목표·이번 범위·제외:
- 정확한 과제/Git root·브랜치·기준 revision·현재 dirty:
- 요구/계획/현업 답변의 정본 경로·ID:
- 내 작성 파일·공유 데이터/외부 효과 소유권:
- 이미 끝난 기능·수정 파일/함수·선택 이유:
- 실제 실행 명령·입력 종류·기대/실제·근거 경로:
- 실패·원인(확정/가설)·수정·회귀 결과:
- NOT_RUN/BLOCKED·해제 조건:
- 남겨 둔 프로세스·포트·사용 환경·중지/복구 방법(비밀 값 제외):
- 미확정·불명 전송·중복 실행 금지 대상:
- 남은 한 작업·정확한 다음 파일·완료 기준·다음 담당:
- 작성권: 유지 / 반환 시각·범위 / 다음 소유자 인수 확인:
- 인수자 읽기 확인 / 실제 착수 / 결과 회수: 각각 별도 기록.
