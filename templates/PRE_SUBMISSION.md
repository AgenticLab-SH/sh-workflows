# 제출 직전 확인

실제 과제 지시와 공식 제출 화면이 우선입니다. 읽기만 하고 완료로 표시하지 않습니다.

- [ ] 필수 산출물이 정확한 과제 경로에 저장되어 있다.
- [ ] 미저장 에디터/외부 변경 충돌을 처리했으며 원본을 임의 덮어쓰지 않았다.
- [ ] 실행법·입출력·필수 기능과 실제 상태를 설명할 수 있다.
- [ ] 검사 결과와 NOT_RUN을 구분했다.
- [ ] 미완료·오류·미확정 규칙을 숨기지 않았다.
- [ ] 차용 자료·라이선스·수정 범위를 적었다.
- [ ] 개인 링크·인증정보·외부 전송 기능이 산출물에 섞이지 않았다.
- [ ] `.hackathon-kit` 등 공개 참고 저장소·합성 연습 파일이 의도치 않게 제출에 포함되지 않는지 공식 안내·미리보기에서 확인했다. 미확인이면 미확인으로 표시했다.
- [ ] 공식 미리보기에서 실제 제출 대상을 확인했다.
- [ ] 참가자가 직접 제출물 확정과 후속 절차를 진행했다.
- [ ] 최종 완료 표시·제출 ID를 공식 허용 방식으로 확인했다.

확정 후 파일을 바꿔도 제출물에 반영된다고 추정하지 않습니다.
실제 AI 금지 단계에서는 AI 호출·자동 답안·복사 붙여넣기를 사용하지 않습니다.
