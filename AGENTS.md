# AI Hackathon Prep Kit contributor and task guidance

- This is a preparation/reference repository. Distinguish the real task root from the cloned kit folder; do not replace the task README, instructions, existing skills, or submission files.
- Begin a time-boxed hackathon with .agents/skills/hackathon-task-driver/SKILL.md. Load only task-relevant additional skills.
- The participant owns problem definition, business decisions, scope and final explanation; the provided coding agent owns only the delegated implementation.
- Separate stakeholder questions, implementation requests, platform help, and incident reporting. Keep requirements, assumptions, decisions, and actual execution evidence distinct.
- Prefer one writer and the provided runtime. Goals, subagents, plugins and MCP are optional only if supported and allowed. Do not activate hidden features or upgrade the agent.
- Follow the current host/model policy for checks. Never execute or delegate prohibited validation. Record omitted checks as NOT_RUN.
- For a web IDE, observe saved files through the authorized terminal. Preserve unsaved-buffer conflicts. The participant operates the built-in Browser; the agent does not claim a visual pass without an observation.
- Use synthetic practice fixtures. Keep private task data, candidate links, credentials and machine configuration out of public source, packages and releases.
- Read docs/SAFE_USE.md and docs/COFA_2026_BRIEF.md for assessment-specific boundaries. During any actual no-AI phase, stop AI assistance rather than answering or generating answer notes.
- Publishing this preparation kit from its owner's environment is separate from using it inside an assessment that prohibits Git Push.
