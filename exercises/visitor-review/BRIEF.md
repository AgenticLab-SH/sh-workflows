# 모의 A: 방문 신청 검토

완전히 가상의 의뢰와 데이터입니다.

> 매일 담당자가 방문 신청 CSV와 규정 문서 두 개를 비교합니다. 판정 이유를 다시 설명하는 일도 많습니다. 담당자가 신청을 검토하기 쉬운 작은 결과물을 만들어 주세요.

제공: applications.csv, policy-old.md, policy-new.md.
처음에는 규정 우선순위·누락·중복·출력·화면 필요 여부가 확정되지 않았습니다.

먼저 문제를 두 문장, 질문 5개, 첫 필수 기능 3개로 정리합니다. 문서 날짜가 더 늦다는 이유만으로 자동 우선 적용하지 않습니다. 그다음 FACILITATOR.md에서 질문에 해당하는 답변을 확인합니다.

코드 완성본은 제공하지 않습니다. 화면이 필요하다면 이유를 설명하고, 파일 결과만으로 충분한지도 질문합니다.
