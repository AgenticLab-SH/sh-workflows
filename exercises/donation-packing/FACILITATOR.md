# 담당자 에이전트 역할 카드 E: 벼룩시장 기부 물품 보관 상자 정리

> 합성 연습 자료, 실제 대회 문제·업무 데이터 아님. 아래 규칙은 모두 자체 제작이며 실제 과제의 규칙으로 재사용하지 않습니다.

참가자(연습하는 사람)는 이 파일을 먼저 읽지 않습니다. 진행자 또는 담당자 역할을 맡은 AI가 이 카드를 들고 질문에 답합니다. 답변 규칙은 [모의 D 역할 카드](../session-allocation/FACILITATOR.md)의 1~7번과 같습니다. 요약하면 구체 질문에만 답하고, 모호하면 "어떤 항목의 어떤 경우를 말씀하시는지 구체적으로 알려 주세요."라고만 답하며, 한 메시지에 질문이 여럿이면 첫 질문에만 답합니다. 답변표에 사실이 있는 확인형 질문에는 그 사실 한 문장으로 답하고, 답변표에 없는 사안의 구체 제안에는 "그 안으로 진행해도 됩니다."라고 답한 뒤 새 규칙으로 기록합니다.

## 숨은 규칙·엣지 케이스 답변표

| 질문 패턴 | 답 |
| --- | --- |
| 상자 한 개의 무게 한도 | 10kg입니다. 정확히 10kg은 담을 수 있습니다. |
| 상자 한 개의 부피 한도 | 40L입니다. 정확히 40L는 담을 수 있습니다. |
| 상자 종류 | 모두 같은 크기 한 종류입니다. |
| `weight`의 `kg`·`g`·단위 없는 숫자 | 모두 그램으로 환산해 계산합니다. 단위 없는 숫자는 kg입니다. |
| `volume`의 `L`·`mL`·단위 없는 숫자 | 모두 mL로 환산해 계산합니다. 단위 없는 숫자는 L입니다. |
| 같은 `item_id`가 여러 행 | `logged_at`이 가장 늦은 행 하나만 유효합니다. 파일 순서가 아니라 시각 기준입니다. |
| ID 앞뒤 공백·소문자(`" i07"`, `i12`) | 공백을 지우고 대문자로 맞춘 ID가 같으면 같은 물품입니다. |
| `weight`가 빈 행 | 상자에 넣지 않고 '확인 필요' 목록에 둡니다. |
| 한 물품이 상자 한도보다 큼 | 상자에 넣지 않고 '따로 보관' 목록에 둡니다. 상자 수에 세지 않습니다. |
| 함께 담으면 안 되는 물품 | `액체`와 `종이`는 같은 상자에 담을 수 없습니다. 그 밖의 조합은 괜찮습니다. |
| 깨지기 쉬운 물품(유리컵 등) | 이번 범위에서는 따로 정한 규칙이 없습니다. |
| `set_id` | 같은 값의 물품은 함께 팔 묶음입니다. 빈 칸은 묶음이 없다는 뜻입니다. |
| 묶음을 꼭 한 상자에 넣어야 하나 | 아닙니다. 되도록 한 상자에 넣고, 나뉜 묶음 수를 결과에 적어 주세요. |
| 무엇을 최소화하나 | 상자 수가 먼저입니다. 상자 수가 같으면 나뉜 묶음 수가 적은 계획이 낫습니다. |
| 같은 상자 수·같은 분리 수 계획이 여럿 | 어느 것이든 됩니다. |
| 결과 형식 | 상자별 목록 CSV(`box_no`, `item_id`, `name`)와 요약(상자 수, 나뉜 묶음 수, 확인 필요·따로 보관 목록)이 필요합니다. 화면은 없어도 됩니다. |
| 사용자 역할 | 창고 담당 한 명이 씁니다. 역할을 나눌 필요는 없습니다. |
| 기준선 방법을 물으면 | 부피가 큰 물품부터(같으면 `item_id` 오름차순) 넣을 수 있는 첫 상자에 넣습니다. 무게·부피 한도와 함께 담기 금지를 모두 지킵니다. |

진행자 메모: 이 모의의 함정은 세 가지입니다. ① 단위 없는 숫자(`I04`의 `3`, 단위가 kg) ② 파일 뒤쪽 행이 더 이른 시각인 중복(`I05`) ③ 부피 기준 기준선과 최적 계획의 큰 차이. 참가자가 묻지 않으면 먼저 알려 주지 않습니다.

## 진행자용 질문 예

**답하는 구체 질문 예** (질문 하나에 사실 하나, 물음표 하나)

1. `I04`의 `weight` 값 `3`은 kg 단위인가요?
2. 무게가 정확히 10kg인 상자는 허용되나요?
3. `액체` 물품과 `종이` 물품을 같은 상자에 담아도 되나요?
4. `I05`의 두 행 중 `logged_at`이 늦은 행만 유효한가요?
5. `I13`처럼 상자 무게 한도를 넘는 물품은 상자 수에서 빼나요?

**답하지 않는 모호 질문 예**

1. 담는 규칙을 다 알려 주세요.
2. 상자를 어떻게 채우면 좋을까요?
3. 데이터에 이상한 데가 있나요?

## 자체 점검표

- [ ] 질문 원장: 데이터에서 뽑은 질문과 데이터에 없는 규칙(한도, 함께 담기 금지, 목적) 질문이 모두 있다.
- [ ] 정제 로그: 위 수치와 같은 값을 직접 계산했고, 확인 필요·따로 보관 물품이 원 ID와 함께 남아 있다.
- [ ] 정식화 카드: 결정 변수(물품→상자), 목적(상자 수, 다음 묶음 분리), 하드 제약 3개, 동점 처리가 있다.
- [ ] 기준선 대비 개선: 같은 데이터에서 상자 수·나뉜 묶음 수를 기준선·개선안·하한과 나란히 적었다.
- [ ] 제약 위반 0: 상자마다 무게·부피 한도 이하, 액체·종이 동시 수납 0건을 실제 출력으로 확인했다.
- [ ] 설명: 왜 이 방법인지, 하한과 비교해 무엇을 말할 수 있는지, 미실행 검사는 무엇인지 말할 수 있다.

정답 코드와 정답 상자 구성은 제공하지 않습니다.
