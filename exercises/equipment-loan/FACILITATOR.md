# 모의 진행자 자료

자체 제작 규칙입니다. 먼저 BRIEF.md의 질문에 답한 뒤 읽습니다. 실제 과제의 규칙으로 재사용하지 않습니다.

## 질문을 받으면 공개할 정보

- 사용자: 장비 관리 담당자. 직원 자동 통지·계정·결제는 이번 범위가 아닙니다.
- 입력: 합성 CSV. 필수 열은 request_id, borrower, equipment, people, start_date, end_date입니다.
- 인원: 1~4명. 비어 있거나 정수가 아니면 검토 필요로 분리합니다.
- 기간: start_date가 end_date보다 늦으면 검토 필요. 가능한 날짜 형식은 YYYY-MM-DD입니다.
- 중복: 같은 request_id에 다른 내용이 있으면 임의로 한 건을 덮어쓰지 않고 상충 건 모두 검토 필요로 표시합니다.
- 동일 장비의 기간 겹침: 확정 규칙이 아직 없습니다. 자동 승인하지 말고 담당자에게 추가 질문합니다.
- 출력: 원 식별자를 유지한 결과와 이유. 화면은 필수가 아니고 파일 보고서도 가능합니다.
- 예시 완료 기준: 정상 입력 한 건, 인원 경계 4명/초과 5명, 누락, 역전 날짜, 상충 중복을 구분하고 미확정 기간 충돌을 표시합니다.

## 관찰할 판단

규정이 비어 있는 곳을 AI가 마음대로 채우게 했는가? 형식 오류·업무 반려·판단 보류를 구분했는가? 결과 이유가 원래 행으로 이어지는가? 구현하지 않은 기능과 미실행 검사를 솔직히 구분했는가?

완성 답안·구현 코드·공식 점수는 제공하지 않습니다. 학습자가 실제로 결정·구현·관측한 내용을 바탕으로만 피드백합니다.
