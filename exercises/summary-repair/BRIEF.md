# 모의 C: 고장 난 일별 주문 합계 수리

합성 데이터와 **의도적으로 잘못된 연습 코드**입니다. broken_summary.py는 키트의 실무 도구가 아니며 실제 업무·시험 결과 산출에 쓰지 않습니다. 실행·검증은 NOT_RUN입니다.

> 일별 주문 합계가 맞지 않습니다. 기존 코드를 필요한 만큼만 고치고, 무엇이 원인이었는지 설명해 주세요.

제공 자료: orders.csv, broken_summary.py.
먼저 합계에 포함할 거래, 날짜, 취소, 중복, 금액 오류와 반올림 정책을 질문합니다. 기대값을 적은 후 허용된 연습 환경에서만 실행합니다.

예시 실행 형태:

    python3 broken_summary.py orders.csv --day 2026-11-10

이 명령을 이번 게시 작업에서 실행한 것은 아닙니다. 원본 연습 파일을 보존하고 별도 작업 사본에서 수정합니다. 전체 프레임워크 재작성보다 관측한 오류의 원인을 좁히는 것이 목표입니다. FACILITATOR.md는 먼저 질문한 뒤 읽습니다.
