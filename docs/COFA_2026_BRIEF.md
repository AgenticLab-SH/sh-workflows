# Cofa 2026 2차 준비 기준

이 문서는 **2026-10-31 SK하이닉스 AI 해커톤 2차** 준비 대화의 안내를 정리한 시점 기록입니다. 다른 회사의 Cofa 평가·다른 연도·일반 채용전형에 자동 적용하지 않습니다. 해커톤의 서류 → 1차 → 2차 → 본선은 같은 대회 안의 단계입니다.

## 근거의 우선순위

1. 응시 당일 운영팀 추가 공지와 해당 과제 화면의 지시.
2. 10월 29일 최종 메일 본문. 10월 26일 가이드와 충돌하면 최종 메일 우선이라고 명시했습니다.
3. 10월 26일 메일 본문과 원래 첨부 가이드.
4. 일반 Cofa 설명·운영진 인터뷰·과거 참가 후기.
5. 이 저장소의 자체 제안과 연습문제.

메일 본문은 보관 대화에서 직접 읽었습니다. 원첨부 5개는 회수 시 403이었으므로 PDF·TXT 원본을 이번에 직접 확인했다고 주장하지 않습니다. 아래에서 첨부 내용은 **기존 답변과 이번에 직접 읽은 Notion 정본의 가이드 해설**이라는 근거 수준으로 구분합니다. 개인 메일 전문과 개인 응시 링크는 공개하지 않습니다.

## 대화·Notion의 첨부 가이드 해설에서 읽은 내용

다음은 원본 첨부 재열람이 되지 않아 이번 작업에서 독립 확인한 공식 문구가 아닙니다. 실제 적용 전에 제공 안내와 대조합니다.

- 웹 IDE의 README·파일 탐색기·에디터·터미널·내부 Browser, 업무 담당자, Cofa Helper.
- 제공된 Codex 사용, 외부 AI 연결 제한, Astra 제한, Computer Use 금지.
- 공개 저장소 Clone 가능, Git Push·개인 PC 파일 업로드·외부 브라우저 직접 사용 제한.
- 후속 질문 6개 × 각 5분, AI·복사 붙여넣기 금지, 이전 답변 수정 불가.
- 제출 미리보기 → 제출물 확정 → 질문 생성 대기 → 후속 답변 → 최종 제출 ID.
- 단일 모니터, 신분증 가림·촬영 구도, 내부 Browser가 요구하는 서버 바인딩.
- 작업 종료 약 10분 전 제출 준비 권고. 이는 180분을 늘리는 규칙이 아님.

## 일반 인터뷰와 이번 대회를 혼동하지 않기

기술·의도·인지 3축은 준비 방향에 유용하지만 공식 배점·합격선은 확인되지 않았습니다. 과거 코파톤의 6시간, Claude Code, 개인 파일 업로드, 평가 에이전트 수나 후속 질문 5개를 이번 시험의 조건으로 옮기지 않습니다. 한 후기의 '2차 실기'가 이번 해커톤의 2차 예선인지도 구분합니다.

공개 참고: [해커톤 안내](https://skhynix-hackathon.com/ai-2026), [대화에 제공된 운영진 인터뷰](https://www.youtube.com/watch?v=CLpN3zl8noQ). 이번 보강에서 영상을 새로 재생하거나 외부 웹 원문을 새로 검증하지는 않았습니다.

## 아직 환경에서 확인할 것

실제 CLI 버전·모델 목록·토큰 표시, /goal·Skill 탐색·subagent·plugin·MCP 제공 여부, 셸·Python·Node·실행 스크립트·서버 포트, 실제 필수 제출 경로입니다. 기능이 없으면 기본 단일 Codex와 터미널로 진행하며 설정을 바꿔 열지 않습니다.

## Notion 본문 대조에서 분리한 세부 사항

Notion 01·08·09·17은 파일 확정과 최종 완료, 일부 파일만 보이는 미리보기, 첫 문항 시작과 이후 문항 자동 진행, 문의 시에도 흐르는 타이머를 구분합니다. [제출·장애 운영](SUBMISSION_AND_INCIDENTS.md)에 정리했습니다. 이는 원 PDF 독립 재확인이 아니라 Notion의 가이드 해설을 직접 읽은 것입니다.

예시 화면의 5문항을 실제 기준으로 쓰거나 과거 '오늘/내일' 표현을 현재 일정으로 옮기지 않습니다. 자세한 [Notion 반영 범위](NOTION_COVERAGE.md)를 참고합니다.
