# 합성 업무 워크플로우 6종

훈련은 필요한 한 유형만 선택한다. 실제 과제에서 이미 답한 질문을 반복하지 않는다.
정답을 외워 적용하지 말고 담당자 답변에 따라 입력 규칙·분기·기대값을 바꾼다.
