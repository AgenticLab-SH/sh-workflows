# 후속 설명 연습 — 실제 AI 금지 단계 이전에만

준비 대화의 가이드 해설은 후속 질문을 6개 × 각 5분, AI·복사 붙여넣기 금지로 설명했습니다. 30분이라는 총 시간은 메일 본문에서도 읽었습니다. 상세 형식은 실제 안내가 우선입니다.

**이 문서는 사전 연습용이며 실제 금지 단계의 답안 자료가 아닙니다.** 금지 단계가 시작되면 AI를 호출하거나 이 양식을 자동으로 채워 답을 만들지 않습니다. 메모 열람도 허용된다고 추정하지 않습니다.

## 연습 전에 정리할 사실

목표 / 구현한 필수 기능 / 주요 파일 역할 / 입력→규칙→출력 / 선택 이유 / 실제 실행한 사례 / 미실행 사례 / 남은 한계를 본인이 설명할 수 있게 합니다. 존재하지 않는 기능을 문장으로 보강하지 않습니다.

## 30분 자가 훈련

실제 본인 결과물을 주제로 아래 자체 질문을 한 번에 하나씩 사용합니다. 공식 기출·예상 정답이 아닙니다. 각 5분 동안 AI와 검색 없이 직접 입력하고, 연습이 모두 끝난 뒤 허용된 환경에서 피드백을 받습니다.

1. 어떤 사용자의 어떤 문제를 해결했고 무엇을 완료 기준으로 삼았는가?
2. 입력이 최종 결과가 되기까지 어느 파일과 규칙을 거치는가?
3. 왜 이 구조를 선택했고 더 복잡한 대안은 왜 쓰지 않았는가?
4. 누락·중복·규정 충돌 때 어떻게 동작하며 그 결정의 근거는 무엇인가?
5. 실제 관측한 정상·실패 사례는 무엇이고 실행하지 못한 검사는 무엇인가?
6. 가장 중요한 한계와 다음 개선 하나는 무엇이며 비용은 무엇인가?

## 답변 구성

**요구사항 → 선택 → 구체적인 구현 위치/동작 → 실제 근거 → 한계** 순서로 짧게 씁니다. 모든 질문에 같은 외운 문장을 반복하지 않습니다.

'예외 처리했다'보다 '인원 누락을 입력 오류로 분리했지만 날짜 형식 검사는 실행하지 못했다'처럼 실제 사실을 구분합니다. 구체적 함수 이름을 기억하지 못하면 지어내지 말고 데이터 흐름을 정확히 설명합니다.

## 연습 후 피드백

[설명 연습 Skill](../.agents/skills/short-answer-defense/SKILL.md)을 사용할 수 있는 사전 학습 단계에서만 요청합니다. 답변의 사실 일치, 선택 근거, 관측 증거, 한계 구분을 봅니다. 문장이 유창하다는 이유만으로 이해했다고 평가하지 않습니다.

## 질문의 전제가 내 결과와 다르면

실제로 DB를 사용하지 않았는데 선택 이유를 묻는다면 사용했다고 꾸미지 않습니다. '실제 구현은 파일 처리였고, 요구가 일회성이어서 그 방식을 선택했다'처럼 본인 결과로 전제를 바로잡습니다. 테스트 개수·수치·함수 이름을 기억하지 못하면 지어내지 않습니다. 사전 연습 후 사실 일치·선택 근거·관측·한계를 대조하며, 실제 금지 단계에서 AI 피드백을 받는 절차가 아닙니다.
