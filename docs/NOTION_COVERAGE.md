- **Git U/M = 미저장:** Git의 추적/변경과 에디터 저장 상태를 구분하도록 보완했습니다.
- **예시 이미지 5문항 vs 가이드 해설 6문항:** 예시 그림을 실제 문항 수의 기준으로 삼지 않습니다. 실제 최신 공지가 우선입니다.

- **공식 규칙과 일반 인터뷰:** 원 PDF를 새로 읽은 것처럼 승격하지 않고 메일 직접 읽기·Notion 가이드 해설·일반 제품 설명·자체 제안을 구분합니다.
- **연구 결과:** 논문 초록/벤치마크 결과를 특정 시험의 점수·채점 방식·개인 성과로 바꾸지 않습니다.
