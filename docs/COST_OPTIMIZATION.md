# 비용 최적화 운영서

사용 한도가 없어도 토큰·호출 수·재시도·실행 시간이 평가될 수 있다고 **가정**하고 일하는 방법입니다. 특정 대회의 배점이 아니며, 공식 규칙·제공 환경·호스트 정책이 항상 우선합니다. 정확성과 필수 산출물이 먼저이고 비용은 그다음입니다.

Skill로 쓸 때는 [cost-aware-execution](../.agents/skills/cost-aware-execution/SKILL.md), 기록은 [COST_LOG](../templates/COST_LOG.md)를 사용합니다.

## 비용 요소

| 요소 | 늘어나는 경우 | 줄이는 방법 |
| --- | --- | --- |
| 입력 컨텍스트 | 저장소 전체 읽기, 큰 데이터 붙여넣기, 같은 파일 재독 | README와 필요한 파일만, 데이터는 프로파일 요약, 상태 요약 노트 재사용 |
| 출력 길이 | 전체 파일 재생성, 긴 설명, 매 턴 체크리스트 출력 | 부분 수정, 짧은 보고 형식 지정 |
| 호출 수 | 작은 수정을 하나씩 요청, 반응 확인 없이 질문을 하나씩 따로 요청·전송 | 관련 수정은 묶어 한 번에. 질문 멘트는 한 턴에 몰아 쓰고, 메시지당 질문 수는 전송 단위 시험 결과에 맞춤 |
| 재시도 | 같은 지시 반복, 원인 없이 다시 실행 | 2회 실패 시 접근 변경, 실제 오류와 기대값만 전달 |
| 도구 실행 | 매번 전체 테스트, 불필요한 설치·빌드 | 좁은 테스트 먼저, 전체는 체크포인트에서 |
| 사람 대기 | 모호한 지시로 되묻기, 큰 결과를 사람이 다시 검토 | 완료 기준·멈춤 조건 명시, 결과 요약 형식 지정 |

## 단계별 규칙

- **시작**: 과제 README·필수 산출물만 읽는다. 인벤토리는 한 번 만들고 요약을 재사용한다. Skill은 1~3개만 로드한다.
- **질문**: 결과·판정·테스트·화면을 바꾸는 질문만 고르고 P0부터 보낸다. P0·P1은 과제 초반(예: 20~30분 안)에 끝내고, P3(표시 문구)는 기본 가정으로 기록한다. 질문은 사실 하나·물음표 하나, 메시지는 한 번 보내는 전송 단위다. 멘트는 Codex가 한 턴에 몰아서 작성한다. 첫 메시지에 번호 붙인 질문 2개를 담아 보내 보고, 둘 다 답하면 메시지당 3~5개로 묶고, 첫 질문만 답하거나 거절하면 메시지당 1개로 보낸다. 업무 담당자 에이전트 호출도 비용이다. 이미 확인한 것은 다시 묻지 않는다.
- **구현**: 작은 기능 하나씩, 대상 파일·완료 기준·멈춤 조건을 적어 위임한다. 계산은 스크립트로 한다. 기계적 수정은 묶어서 한 번에 맡긴다.
- **디버깅**: 실제 오류·관련 파일·기대값만 전달한다. 같은 실패가 2회면 가설·범위·입력을 바꾼다. 어려운 디버깅에만 높은 추론을 쓴다(제공 메뉴가 있을 때).
- **검증**: 바꾼 부분의 좁은 테스트를 먼저, 전체는 체크포인트에서 실행한다. 비용 때문에 필수 검사를 줄이지 않는다. 정책이 금지한 검사는 NOT_RUN이다.
- **제출**: 새 기능을 멈추고 COST_LOG의 실제 기록으로 "비용을 줄이려고 한 일 3가지"를 정리한다.

## 점검 루틴

1. 기능 1개 완료 또는 30~45분마다 멈춘다.
2. `/status` 같은 사용량 표시가 **제공될 때만** 확인한다. 없으면 대략의 턴 수를 센다.
3. COST_LOG에 한 줄 적는다.
4. 낭비 신호를 확인한다: 같은 파일 재독, 긴 출력, 같은 실패 반복, "전부 개선해" 같은 넓은 지시.
5. 컨텍스트가 커졌으면 상태 요약 노트(결정·확정 규칙·남은 일)를 갱신하고, `/compact` 또는 `/new`가 **제공될 때만** 압축하거나 새 세션에 인계 요약을 붙인다.

## 하지 말 것

- 비용을 이유로 필수 검증·입력 검증·사람 승인·정확성을 줄이지 않는다.
- 사용량을 숨기거나 측정값을 꾸미지 않는다. 기록은 실제 관측만 적는다.
- Codex 업데이트, 설정 파일·숨은 플래그 변경으로 모델이나 한도를 바꾸지 않는다. 모델·노력 수준은 제공 메뉴(예: `/model`)가 있을 때만 바꾼다.
- 비용을 줄이려고 허용되지 않은 외부 AI·도구로 작업을 옮기지 않는다.

## tools/context_budget.py

읽기 전용으로 파일별 bytes·줄 수·추정 토큰을 큰 순서로 보여 줍니다. 파일 내용은 출력하지 않습니다. 토큰은 ASCII 약 4자당 1, 비ASCII 약 1자당 1로 잡은 단순 근사이며 실제 토크나이저 값이 아닙니다.

    python3 .hackathon-kit/tools/context_budget.py --root . --limit 10
    python3 .hackathon-kit/tools/context_budget.py src data --root . --budget 20000

- `--root` 밖 경로는 오류(exit 2)입니다. 경로를 생략하면 root 전체를 봅니다.
- `.git`·`__pycache__`·`node_modules`·`.hackathon-kit`(과제 루트에 복제한 참고 키트)·`.venv`·`venv`, 널 바이트가 있는 바이너리, 5MB 초과 파일, 심볼릭 링크는 제외하고 `excluded`에 수를 셉니다.
- exit 0 정상, 1 `--budget` 초과, 2 입력 오류(`{"error": ...}`).
- 결과의 큰 파일은 통째로 읽히지 말고 요약·부분 읽기 대상으로 정합니다.
