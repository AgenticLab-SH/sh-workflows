## 이 변경에서 하지 않은 일

개인 Notion의 페이지 이동·수정, 원 PDF/TXT 재회수, 최신 웹 조사·영상 재시청, 개인 링크 접속, 사전 체험 시작, 실제 시험 도구 사용, 시험 문제·완성 답안 제작, 원 Git 번들 복원을 수행하지 않았습니다. 이 항목들은 문서 작성이나 패키지 생성으로 완료 처리하지 않습니다.

해당 대회의 구체 규칙은 이후 공지와 실제 화면이 우선입니다. 다른 기업의 Cofa 안내나 옛 코파톤 조건을 이번 대회에 합치지 않습니다.
