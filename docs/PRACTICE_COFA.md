# 자체 실전 훈련 6묶음

실제 기출을 재현하거나 다음 문제를 예측하지 않습니다. 합성 자료와 본인 연습 프로젝트만 사용합니다. 문제를 받자마자 완성 답안을 AI에 요청하기보다 먼저 판단을 작성합니다.

## A. 담당자 질문 — 10분

[장비 대여 의뢰](../exercises/equipment-loan/BRIEF.md)를 읽고 핵심 문제, 질문 4개, 첫 필수 기능 3개를 적습니다. 그다음에만 [진행자 자료](../exercises/equipment-loan/FACILITATOR.md)에서 질문에 해당하는 규칙을 확인합니다. 질문하지 않은 정보가 처음부터 주어졌다고 기록하지 않습니다.

## B. 규정 충돌 — 10분

연습 조건: 오래된 문서에는 '최대 5명', 새 공지에는 '최대 4명'이라고 되어 있습니다. 적용일이 불명확합니다. AI에게 4명을 임의 채택시키기 전에 문서 권위·적용일·소급 여부를 누구에게 확인할지 적습니다. 둘 다 적용 가능한 상황이면 보류·설명 정책을 질문합니다. [규정 조정 Skill](../.agents/skills/document-rule-reconciliation/SKILL.md)을 선택할 수 있습니다.

## C. 과설계 줄이기 — 10분

읽기 전용 CSV 보고서가 필요한데 AI가 로그인·DB·메시지 큐·에이전트 5개를 제안했습니다. 어떤 요구에 필요한지 한 항목씩 따져보고, 당장 지울 설계와 남길 필수 기능을 이유와 함께 적습니다. '항상 DB가 나쁘다'는 결론으로 일반화하지 않습니다.

## D. 시간·토큰 판단 — 10분

90분이 남았고 필수 규칙 하나와 입력 오류 처리가 빠져 있습니다. 선택지는 새 MCP 설정, 전체 재설계, 필수 규칙 보완, 시각 효과 추가입니다. 목표·통합 비용·검사 가능성을 기준으로 우선순위와 중지 시각을 정합니다. 공식 배점이나 토큰 총량을 가정하지 않습니다.

## E. 코드 이해와 근거 — 15분

본인이 만든 작은 기능 하나의 입력→처리→출력을 손으로 설명합니다. 필수 열이 사라지거나 같은 식별자가 중복되면 어디에서 어떤 상태가 되는지 예상합니다. 검사가 허용되면 실제 관측과 비교하고, 금지되면 예상과 NOT_RUN을 구분합니다. 다른 사람의 완성 코드를 이해한 척하지 않습니다.

## F. AI 없이 서술 — 30분

[6개 설명 질문](NO_AI_REHEARSAL.md)을 각 5분으로 직접 작성합니다. 실제 금지 단계가 아닌 사전 모의에서만 수행하고, 답변 이후 피드백을 받습니다.

## 통합 모의의 산출물

- 확인한 요구와 미확정 규칙.
- 가장 작은 구현 또는 설계. 과제가 화면을 요구할 때만 화면 포함.
- 필수 입력·경계·누락·중복 사례의 기대값.
- 실제 실행 결과 또는 NOT_RUN, 오류와 남은 한계.
- 결정 한두 개의 이유와 차용한 공개 자료.
- 직접 작성한 사전 설명 연습.

각 항목을 '작성됨 / 실제 관측됨 / 아직 안 함'으로 분리합니다. 자체 체크를 공식 점수·합격 가능성으로 환산하지 않습니다.

## 파일을 가지고 통합 연습하기

[통합 모의 5종](MOCK_EXAMS.md)은 Notion 10번의 방문 신청·고객 문의·합계 오류 수리를 위한 합성 의뢰·자료·진행자 규칙을 제공합니다. 합계 연습의 broken_summary.py는 의도적 오류를 포함하며 실무 처리 도구가 아닙니다. 현재 검사·동작 확인은 NOT_RUN입니다.

[합성 모의 D: 문화센터 강좌 배정](../exercises/session-allocation/BRIEF.md)은 실전 보강 경로를 한 번에 연습합니다. 진행자는 [역할 카드](../exercises/session-allocation/FACILITATOR.md)대로 구체 질문에만 답합니다. 권장 순서는 [오버라이드 확인](OVERRIDE_INSTRUCTIONS.md) → [질문 원장](../.agents/skills/stakeholder-agent-questioning/SKILL.md)과 복사용 멘트(결과를 바꾸는 애매한 점 전부, P3는 가정, 한 턴에 묶어 작성, 전송 단위는 반응을 보고 결정) → [역할 매트릭스](../templates/ROLE_MATRIX.md) → [정식화 카드→기준선→개선](../.agents/skills/optimization-modeling/SKILL.md) → 기능마다 [비용 한 줄](../templates/COST_LOG.md)입니다. 사람 진행자와 연습할 때는 질문을 2~3개씩 묻습니다.
