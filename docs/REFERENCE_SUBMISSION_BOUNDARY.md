# 공개 참고 키트와 실제 제출물 분리

이 문서는 **공개 GitHub 자료가 허용된 작업 환경**에서 참고 저장소를 가져올 때의 실수 방지 안내입니다. 과제별 제출 범위는 운영팀·실제 README·공식 제출 UI가 결정하며, 이 문서 자체로 다운로드·외부 통신·파일 제출 권한이 추가되지 않습니다.

## 왜 중요한가

`git clone --depth 1 https://github.com/AgenticLab-SH/sh-workflows.git .hackathon-kit`은 공개 키트를 <b>작업 폴더 아래</b>에 복제하는 예시일 뿐입니다. 일부 자동 수집·제출 방식에서는 `.hackathon-kit` 같은 **숨김 폴더도 제출 후보에 포함될 수 있습니다**. Git의 `.gitignore` 또는 폴더 이름이 `.`로 시작한다는 사실만으로 자동 제외를 보장할 수 없습니다.

따라서 기본 구분은 다음과 같습니다.

| 파일 종류 | 역할 | 제출 전 판단 |
| --- | --- | --- |
| 실제 과제 README·제공 입력 | 과제 이해·구현의 기준 | 원본 보존, 지시 우선 |
| 요구된 코드·결과·문서 | 필수 제출 후보 | 저장·실행·근거 확인 |
| `.hackathon-kit/**` | 공개 참고/훈련 자료 | 제출 범위에 잘못 들어가는지 확인 |
| 키트 내 `examples/**`, `exercises/**` | 합성 연습 파일 | 실제 과제의 정답/출력으로 전용하지 않음 |
| 로그·임시 파일·토큰·개인 링크 | 제출에 불필요하거나 민감 | 불필요한 외부 공개/제출을 막음 |

## 단계별 확인

1. **실제 과제 루트**에서만 공식적으로 허용된 읽기 명령을 사용한다. 아래는 저장 파일 확인용 예시다.

   ```sh
   pwd
   ls -la
   find . -maxdepth 2 -type f | head -80
   git status --short
   ```

   `find`/Git 명령을 지원하지 않으면 설치하거나 보호된 경로를 뒤지지 않는다. **문제 본문/토큰/비밀 파일 내용을 출력·외부 전송하지 않는다.**
2. README가 지정한 **필수 출력 파일과 경로**를 확인해 목록으로 만든다. 키트는 별도 참고 루트로 표시한다.
3. 제출 미리보기에서 실제 후보 파일·확정 단계를 **참가자가 직접** 확인한다. CLI의 Git 상태/파일 목록만으로 플랫폼의 제출 수집 범위를 확정하지 않는다.
4. 미리보기에서 키트가 포함되는지 불확실하다면 **Cofa Helper/최신 공식 안내**에 제외 방법을 문의한다. 파일 삭제·이동·AGENTS.md 덮어쓰기·제출 방식 변경을 임의로 수행하지 않는다.
5. 제외가 지원되지 않거나 확인이 불가능하면 미확인으로 기록하고, 과제 요구와 운영팀 지시를 우선한다. 시험 중 Git Push·외부 업로드·스크린샷·자동 GUI 조작으로 문제를 해결하려 하지 않는다.

## 빠른 지시문

```text
실제 과제의 README에서 필수 제출 파일/경로를 확인하라.
저장된 작업공간에서 실제 출력 파일과 참고 키트(.hackathon-kit 등)를 구분해라.
파일별 상태를 TASK_INPUT, TASK_OUTPUT, REFERENCE_KIT, GENERATED_TEMP,
UNCONFIRMED로만 요약하고, 민감한 원문은 출력하지 마라.
참고 키트를 삭제/이동하거나 과제 설정을 변경하지 마라.
공식 제출 미리보기를 내가 직접 확인할 것이며, 이를 자동 확인했다고 말하지 마라.
```
