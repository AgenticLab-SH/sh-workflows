# 2026-10-31 시험 당일 한 장 운영표

이 문서는 **사전 준비용 범용 운영표**입니다. 실제 시험 화면, 최신 공식 메일 및 현재 모델·호스트 정책이 항상 우선합니다. 이 자료는 공식 시험 답안이나 사용권 확대 수단이 아닙니다.

## P0. 시작 전에 확인

- **09:10 접속 시작 권장(자체 계획)**, **09:40까지 접속·감독 준비 완료(공식)**, 09:40 추가 이메일 확인. **10:00 직접 시작**, **14:00 종료**, 연장 없음.
- PC Chrome·웹캠·전체 화면 공유·모니터 1대. 외장 키보드/마우스는 유선만, Bluetooth 입력장치 사용 불가.
- Proctor는 휴대폰 Wi-Fi·충전·공식 앱 연결과 촬영 구도 확인. 실물 신분증 준비.
- **제공 Codex 버전은 업데이트하지 않는다.** 10/29 권장 목록은 6.1 Sol·5.6 Terra·6.0 Luna; 실제 사용 가능한 모델은 제공 환경에서 확인.
- 사전 체험 1회·15분을 아직 사용하지 않았다면 본시험 과제 시작 **전**에만 본인이 진행. 사전 체험을 시작했다고 본시험을 시작한 것으로 추정하지 않는다.

## P1. 첫 10~20분: 먼저 문제를 이해하기

1. 실제 과제 루트와 README·첨부 파일·필수 출력/제출 경로를 확인. 공개 키트는 **참고 자료**, 과제 자체가 아니다.
2. **사용자 / 목적 / 입력 / 규정 / 출력 / 미확정 / 완료 기준**의 7칸으로 분해.
3. 결과를 바꾸는 핵심 불확실성만 현업 담당자에게 질문. 플랫폼 조작과 규정 질문은 Cofa Helper / 업무 담당자를 구분.
4. 필수 MVP와 제외할 기능을 정한 후 제공 Codex에게 작은 첫 구현을 맡김.

### 제공 Codex에 첫 지시(허용된 작업 단계에서만)

```text
실제 과제 루트와 현재 README·저장된 파일부터 확인해라.
공개 참고 키트는 과제 파일이나 제출 대상이 아니다.
목표, 필수 산출물, 업무 규칙, 미확정 조건, 구현 시작점을 간단히 구분해라.
지금은 코드·설정·Codex 버전을 변경하지 말고 내가 결정할 질문만 제시해라.
브라우저 에디터의 미저장 내용이나 화면을 봤다고 주장하지 마라.
```

## P2. 구현·검증: 작은 첫 완성본

- 필수 입력→규칙→출력 하나를 먼저 실행 가능하게 만든다. DB·배포·MCP·Goal·다중 에이전트는 과제 요구와 실제 제공/허용이 확인됐을 때만.
- 예상값과 실제 실행을 구분한다. 정상·경계·누락/충돌 사례의 관측 근거가 없으면 **NOT_RUN**.
- 터미널로 **저장 파일**을 읽고, 실제 파일과 에디터 미저장 버퍼가 다르면 덮어쓰기 전 확인. GUI는 참가자가 공식 Browser로 수동 확인.
- 실패 시 실제 오류·명령·관련 파일부터 좁힌다. 같은 불명 요청 무한 재전송·큰 구조 재작성 금지.
- 체크포인트: 시간 부족 시 새 기능 중단→필수 출력/저장→기본 오류 검증→제출 준비.

## P3. 제출은 '저장'과 다르다

- 실제 과제 지시에서 필수 파일·경로를 확인하고, 합성 예제/참고 키트 전체가 제출에 섞이지 않는지 점검. **숨김 폴더가 자동 제외된다고 가정 금지**. [참고 자료와 제출물 경계](REFERENCE_SUBMISSION_BOUNDARY.md).
- 공식 미리보기에서 후보 파일을 직접 확인하고 제출물 확정. 미리보기가 모든 파일을 보여준다고 단정하지 않음.
- 제공 절차에 따라 **파일 확정 → 질문 생성/대기 → 후속 직접 답변 → 최종 완료 표시**. 과제 180분과 후속 30분·대기 시간을 모두 14:00 이전에 관리. 마지막 10분만을 믿고 제출을 미루지 않는다.
- 실제 **AI 금지 후속 단계**가 시작되면 AI·Skill·프롬프트·복붙으로 답안 작성하지 않는다. 스스로 설명.

## P4. 문제가 발생하면

- 저장 실패/에디터 충돌: 공식 저장 표시와 저장 파일을 비교, 양쪽 작업 보존.
- 서버 미리보기 실패: 실제 서버→포트→바인딩→경로→수동 새로고침 순서.
- AI·감독 장애: 공식 문의 버튼에 **발생 시각·증상** 제출. 타이머 정지/시간 연장 자동 인정 금지.
- 공개 GitHub Clone 실패: 공개 자료는 선택 사항. 문제·서버·계정 제한 우회에 시간을 쓰지 않고 기본 Codex로 과제를 계속.
